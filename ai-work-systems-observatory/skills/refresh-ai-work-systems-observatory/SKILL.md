# Refresh AI Work Systems Observatory

1. Read the saved setup, observed ledger, proposed model, report contract, and existing app data.
2. Reuse every established source, date-window rule, bounded conversation-search condition, and visibility setting unchanged unless the requester names a replacement.
3. Re-run inventory collection and the approved operating-model discovery for roles, rhythms, handoffs, decisions, friction, approvals, outputs, consumption, and run health.
4. Keep prior confirmed facts only when still supported. Downgrade stale facts to inference or unknown; never silently preserve ownership or health.
5. Reapply lifecycle classification and every current-system qualification gate.
6. Recalculate qualified-system consumption coverage using the same definition and population rule.
7. Re-run the strategist synthesis pass. Recommendations may change, but stay in the proposed layer and cite current evidence.
8. Validate all three documents, update the runtime report data, and verify the app.
9. Summarize what changed in observed state, what changed in recommendations, and which unknowns still need one focused answer.

A bare refresh means all established sources unchanged. Do not widen scope or add external writes.
