# 04 - The Sophistication Gate

The package serves an expert and a beginner from the same interview. The first two questions decide which experience you get. You are never asked "how good are you," it is inferred from how you answer.

## The three paths

### Expert
Signal: you describe a real, repeatable process, name specific inputs (reviews, past winners, competitor scans), and already have banks or saved swipe.
Experience: full extraction. Runneth captures *your* engine and runs it as configured. Your answers override the defaults.

### Partial
Signal: you have instincts and raw material but no system. You can point at what you look at, but not a repeatable order.
Experience: hybrid. Runneth proposes the default engine order from `02`, then adjusts it to your answers. It fills gaps with whatever's already confirmed in the three shared banks (per `05`'s check-before-building step, these may already be seeded from real ad evidence, either from an earlier run of this process or from another package writing to the same shared location) and flags where it guessed so you can correct it.

### Starting out
Signal: your honest answer is close to "I look at a competitor and copy what works."
Experience: opinionated default. Runneth runs the default engine and whatever's already confirmed in the shared banks out of the box so you get a real concept immediately, then upgrades you one step at a time (start with real reviews, then personas, then angles). If the shared banks are also empty, `05`'s bank-building process runs first to seed them from your real ad library before a concept can ship.

## Why it works

The expert gets their own taste amplified. The beginner gets a working engine on day one and a path to grow into it. Nobody hits an empty screen, and nobody has their judgment overwritten.

## How the gate is applied

Runneth states which path it detected before running, addressed to the person directly and warm about it either way, not clinical. State it as a read on them, not a label:

- **Expert:** "Sounds like you really know what you're doing here, you've got a real, repeatable process with named inputs. I'm going to capture that as you describe it and let your answers override the defaults instead of proposing my own structure."
- **Partial:** "Sounds like you've got real instincts and good raw material to work with, just not a fixed system yet. I'll propose a structure and adjust it to what you tell me as we go."
- **Starting out:** "Sounds like there isn't a strong system in place yet, that's completely fine. I'll run a solid default for you so you've got something real from day one, then we build it up together."

Use the person's name when it's known. You can override the detected path at any time.
