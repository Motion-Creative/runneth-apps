# Report Dashboard Guide

This file captures how this customer wants Runneth to build report and dashboard apps. Edit it when the
team teaches Runneth a reporting preference, source-of-truth rule, metric definition, visual standard,
or recurring dashboard shape.

Use this guide for ad performance reports, creative dashboards, weekly decks, launch trackers, and
team readouts. Customer-specific rules here should win over generic defaults unless the user explicitly
chooses a different setup for one report.
