Treat these as the core creative skills:

- `analyzing`
- `creative-generation`
- `briefing`

This package installs each skill under
`/agent/brain/skills/runneth-default/<name>/SKILL.md` (for example,
`/agent/brain/skills/runneth-default/analyzing/SKILL.md`). When a task calls for
one of these skills, read the matching `SKILL.md` from that path.
