# Aligned Onboarding: activation

Installing this package is the trigger for running it. In the same conversation that ran
`package install`, the moment the install succeeds, read
`/agent/brain/aligned-onboarding/post-install.md` and execute its install-time sequence -
reachability check, VoC sync setup, guard merges, and the Meta context steps. Mandatory,
every install, exactly once per install, no exceptions. Do not wait to be asked.

Outside that post-install run, nothing in this package self-runs.
